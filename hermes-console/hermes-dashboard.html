How Claude Uses This token efficiency

Claude Desktop calls the qmd MCP server: it searches first (keyword/BM25, no inference), gets back document IDs and snippets, then retrieves only the specific files or line-ranges it needs — never the whole repository. Indexing is incremental, so unchanged files are never re-sent.

Reasoning Model controlled in Claude Desktop

Default is Claude Sonnet 5 (medium reasoning). Say "use Opus" to route a session to Opus. Hermes/qmd are model-agnostic — they only return context; Claude does all reasoning. Local Qwen 3 8B and llama.cpp are fully severed from Hermes and serve production only.

Ask Hermes repository search · no inference

Hermes searches the indexed repository (keyword/BM25) and returns the most relevant files and snippets. For reasoning, ask Claude Desktop — it uses this same index.
